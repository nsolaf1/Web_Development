### Project Requirements

Each project should demonstrate the practical application of full-stack and mobile development concepts. Depending on the selected topic, students should aim to implement:

- **User Authentication:** Registration, login, roles, and permissions.
- **Database Integration:** Data storage, retrieval, updating, and deletion.
- **Frontend Development:** Responsive web interfaces or mobile application screens.
- **Backend Development:** REST API endpoints and business logic.
- **Admin Dashboard:** Tools for managing users, content, and system data.
- **Security:** Input validation, access control, and secure data handling.
- **Testing:** Functional testing and error handling.
- **Documentation:** Project description, database design, and setup instructions.

### Recommended Technologies

- **Frontend / Mobile:** Flutter, React Native, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js, Django, Flask
- **Database:** MySQL, PostgreSQL, MongoDB, Firebase
- **Cloud / Tools:** Docker, REST API, GitHub, Firebase Cloud Messaging

### Note to Students

Students may propose their own project topics, provided that the proposed topic is approved by the instructor before development begins.
